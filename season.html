How the numbers work

Rest-of-season value (ROS): each player's projected fantasy points per game (preseason consensus, blended with this season's actual production, which counts more as games pile up) turned into an expected locked score per week, times the weeks he's expected to play from now to week 24. Known injuries (ESPN return dates, live Sleeper status) remove weeks.

This week: for each player, the expected locked score from what's left of the week. This includes the games he has left, the chance he plays them (Out 0%, Doubtful 25%, Questionable 65%, Day-to-day 80%), and a finished game you can still lock. The best lineup maximises the total.

Lock-In: after a game, lock it if it beats the expected value of waiting for his remaining games. The bar rises with more games left and drops if he might miss games. If his next game has started, that game can no longer be locked. His last game of the week counts automatically.

Waivers: for each free agent, the drop from your roster that improves your lineup value the most, and by how much.

Trades: both teams' lineup value before and after, using the same values. A 2-for-1 credits the open roster spot with a typical free agent. "Helps both" means our model says neither side loses value. Real managers may value players by name or ADP, so the market column helps you pitch it.
